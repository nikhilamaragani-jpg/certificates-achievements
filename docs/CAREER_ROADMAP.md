# Data Analyst career roadmap

## Career direction

The primary goal is to become a strong **Data Analyst specialist**. Business intelligence, Power BI, advanced analytics and cloud analytics are adjacent specializations; analytics engineering and data engineering are later extensions, not replacements for the analyst goal.

```text
Data Analyst foundation
        ↓
SQL + Python/Pandas + statistics + visualization
        ↓
BI / Power BI specialization
        ↓
Advanced and cloud analytics
        ↓
Analytics engineering (dbt)
        ↓
Data engineering (longer-term extension)
```

## Current verified milestone

- **Completed:** IBM *Introduction to Data Analytics* (October 3, 2026), the first course in the IBM Data Analyst Professional Certificate.
- **Additional evidence:** Power BI and Python workshop certificates; AI internship and industrial training certificates.
- **Not yet represented as complete:** the remaining IBM Data Analyst courses, a full professional certificate, Microsoft PL-300, Google certificates, cloud programs, dbt training and engineering programs.

## Planned learning sequence

| Stage | Planned focus | Status |
|---|---|---|
| 1. Foundation | Continue the IBM Data Analyst program: Excel, Python, SQL, data preparation, analysis, visualization, capstone and career preparation. | Course 1 completed; remaining courses not claimed as complete. |
| 2. SQL depth | Practice querying, joins, aggregation, subqueries, CTEs and business problem solving. | Planned. |
| 3. BI specialization | Build Power BI capability in data preparation, modeling, DAX, visualization, deployment and security; prepare for PL-300. | Workshop evidence available; professional certificate and exam not claimed as complete. |
| 4. Advanced analytics | Deepen statistics, regression, experimentation and machine-learning fundamentals after the core. | Planned. |
| 5. Analyst extensions | Add applied GenAI and cloud analytics (BigQuery/Looker) with validation and governance. | Planned. |
| 6. Later engineering layer | Learn analytics engineering with dbt, then consider data engineering, Fabric and cloud engineering. | Longer-term plan. |

The detailed course order is a learning plan, not a claim that enrollment or completion has occurred. Update this page as each milestone is earned and add corresponding project evidence.

## Portfolio progression

The first project in this repository is an introductory, synthetic-data exercise: [Claims Operations: Analyst Foundations](../projects/claims-intelligence-foundation/README.md). It focuses on framing a business question, defining KPIs, checking data quality, summarizing results and documenting limitations.

The project can grow in stages as skills are learned: SQL investigation, Python analysis, a Power BI model and report, statistical investigation, then cloud and dbt extensions. Do not describe later stages as implemented until their code and evidence exist.

## Job-search direction

Target entry-level Data Analyst and BI Analyst roles. International applications should be matched to each role's actual location, language, relocation and work-authorization requirements. Express interest in Germany, Switzerland and broader Europe without implying that a visa, sponsorship or relocation arrangement is guaranteed.
